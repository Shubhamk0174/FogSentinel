🎓 Faculty Examination Defense & Theoretical Guide
Comprehensive technical answers to anticipated faculty and viva questions
1. What represents "one record" in FogSentinel? Is it a single packet or payload? ▼
No, one record is not a raw network packet. It is a 115-dimensional continuous statistical summary vector extracted over 5 exponentially decaying sliding time windows (λ = 0.01, 0.1, 1.0, 3.0, 5.0) by a network stream aggregator. It captures packet size statistics, stream weights, packet jitter means and standard deviations, socket covariance, and radii. Feeding raw packet bytes into ML at the edge is too noisy and compute-intensive; these statistical stream vectors capture temporal botnet flood behavior.
2. Why did Random Forest outperform Deep Neural Networks (MLP)? ▼
We empirically evaluated Logistic Regression, a Multi-Layer Perceptron (MLP) neural network, and Random Forest on 6,600 unseen test records. Random Forest achieved 99.98% accuracy, significantly outperforming the MLP (90.71% multi-class accuracy). In modern tabular machine learning literature (e.g., Grinsztajn et al., NeurIPS), decision tree ensembles consistently outperform neural networks on continuous statistical tables because decision trees construct axis-aligned step boundaries that cleanly isolate abrupt shifts like UDP and SYN flood bursts. In addition, Random Forest executes in 0.0066 ms per record, enabling 151,500 predictions/sec on edge hardware.
3. How do you mathematically explain the latency difference (9.38 ms vs. 206.98 ms)? ▼
In iFogSim2, total end-to-end response latency is the sum of propagation, transmission, queueing, and processing times:
Latency = T_prop(up) + T_trans(up) + T_queue + T_proc + T_prop(down) + T_trans(down)

• Fog Placement: Traverses only the local LAN link (propagation = 2.0 ms each way). With 1,000 MIPS processing effort on a 4,000 MIPS gateway (approx 0.25 ms execution + 5 ms queueing), total response time is 9.38 ms.
• Cloud Placement: Must traverse the physical WAN link twice (100 ms uplink + 100 ms downlink = 200 ms minimum physical speed-of-light delay). Even with a fast 44,000 MIPS cloud server, total latency is 206.98 ms.
Fog computing fundamentally eliminates the WAN propagation bottleneck.
4. Does Fog placement always save energy? ▼
No, Fog computing does not consistently save energy. In our simulations, the Fog node consumed slightly more energy in Fog placement (5,022.25 kJ vs 5,005.99 kJ) because its CPU was actively computing the 1,000 MIPS classification rather than simply routing packets. Fog computing is optimized for low response latency, bandwidth preservation, and privacy, not global energy reduction.
5. Does FogSentinel physically disconnect devices upon attack detection? ▼
FogSentinel is an academic research prototype and simulation framework. When an attack is detected, it generates a simulated action labeled QUARANTINE_RECOMMENDED. In a production industrial deployment, this event would trigger a REST API call to a Software-Defined Networking (SDN) OpenFlow controller (such as OpenDaylight or ONOS) to dynamically inject flow-drop rules into the physical switch.
